# Area pages

One page per module or area, written over time with `/learn handbook modules/<name>`. Each page should answer, with real paths: what the area owns (models, storage, entry points), its use cases, what it exposes to or consumes from other areas, its tests, and the three or four things a newcomer gets wrong.
