# Changelog

## 0.1.0 (unreleased)

First public release.

- CLI: `init`, `update`, `doctor`, `stacks` (Node 18+, no dependencies, Windows, macOS, Linux).
- Skills: `/onboard`, `/feature`, `/build`, `/change`, `/learn`, `/ship`, `/status`.
- Reviewer subagent, cross-platform Stop hook (`verify-build.js`), path-scoped rules guide.
- One living document per feature (`_features/<slug>/feature.md`) with an index for name and work item resolution.
- Handbook skeletons, ADR guide, project plan template, `AGENTS.md` for other coding agents.
- Work item lookup for /change: GitHub issues via `gh`, Azure DevOps via a PowerShell read script.
- Stack packs: `dotnet` (EF Core `/migrate`, Razor rules example), `node` and `python` (profile hints).
